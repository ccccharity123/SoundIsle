# 声屿 · Sound Isle 独立播放器 v1.0.0

从摩羯座 v4.5.9-ui-beta 拆分的**独立 SillyTavern/iOSTT 音乐扩展**。只加载音乐播放器，不运行拾忆、留痕、回响和生成提示词拦截器。

## 安装

**推荐 Git 安装**：将项目根目录的全部文件上传到一个独立 GitHub 仓库（仓库根目录必须直接包含 `manifest.json`、`index.js` 和 `style.css`）。在 SillyTavern / 支持 Git 扩展安装的 TT 中打开「扩展 → 安装扩展」，输入仓库地址（形如 `https://github.com/你的用户名/SoundIsle`），安装后刷新并启用 **声屿 · Sound Isle（独立播放器）**。点击悬浮声屿灵动岛打开播放器。

更新时通过扩展管理器的更新功能拉取仓库新版本（前提是宿主支持 Git 更新）。

## 包含

- 本地/角色歌单、音乐队列、播放模式、音量与音质选择（可用时）
- 网易云兼容网关配置、歌曲搜索和自动匹配（需要自行合法配置可用服务）
- 带双语歌词的播放器、Compact/半屏/大半屏、Media Session（宿主支持时）、浮动灵动岛
- 液态玻璃外观、背景、字体和自定义 CSS、苹果风格下拉菜单
- `<bgm>` 剧情音乐标签跟随（宿主提供聊天读取接口时）
- 音乐库 JSON 导入导出与合并恢复

## 不包含

拾忆、剧情摘要、表格、人物档案、回响、共鸣剧情时间轴、预设插入、记忆 API 和自动隐藏正则。隐藏 `<bgm>` 请自行在酒馆全局正则设置配置“仅显示层替换”，不影响原始聊天消息。

## 兼容和数据说明

本包保留原版播放器的 `sound_isle_v01_library` 音乐库键，以及外观/音乐服务配置键。不要在同一酒馆同时启用完整摩羯座和本独立版：两者的 CSS 选择器、音乐实例和数据键会冲突。它适合朋友**独立安装**。

音乐播放受浏览器自动播放限制；外部音源需满足版权、CORS 和服务可用性要求。离开浏览器后是否能播放取决于设备和宿主，不能保证系统杀死进程后继续播放。

此版本通过文件结构、静态模块依赖及 JS 语法检查；**尚未在 TT/iOSTT 手机上实测**。首次安装请先备份音乐库。


## 维护与发布

修改后先执行 `node --check index.js`、检查其他 JS 语法和模块依赖，再更新 `manifest.json` 版本号并提交 Git。请勿上传 API 密钥或个人数据。可参考 `GIT-DEPLOY.md`。

## 1.0.1 纯净玻璃主题整理

已移除旧版彩色播放器主题、银蓝手账主题及旧主题快捷模板，默认统一为无色液态玻璃。日间/夜间/跟随系统、材质选项、用户自定义背景、字体和 CSS 保持可用。旧设置中的 `playerTheme` 不再应用，不删除其他设置及历史数据。

## v1.1.0：悬浮控件

打开「声屿 → 设置 → 外观 → 悬浮控件」即可调整：

- **显示样式**：悬浮球（播放时保持小球）／灵动岛（播放时自动展开，显示同步歌词和翻译）。
- **停靠位置**：自由拖动（并记住位置）／锁定当前位置／酒馆顶栏正中下方／输入栏正中上方。

顶栏与输入栏停靠会优先读取 SillyTavern 的实际 DOM 位置；当宿主自定义主题隐藏或替换对应组件时，播放器不会消失，而是留在视口内的安全位置。部分深度改造的 TT 宿主可能需要补充选择器。

## v1.1.3 悬浮控件隐藏与唤起

进入「声屿 → 设置 → 外观 → 悬浮控件 → 隐藏与唤起」，可选择四种显示策略并独立开启顶栏、输入栏、Alt+M、边缘双击入口。键盘快捷键在文本输入焦点时不触发。完全隐藏时自动保留至少一个可见音乐按钮。关闭悬浮控件不会停止音乐。iOSTT 与安卓本地部署 SillyTavern 均需实机验证不同布局的自适应入口。
